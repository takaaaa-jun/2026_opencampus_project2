## 現在の判定

`actions.closs` は、左右の前腕が近く、片方が水平・もう片方が鉛直に近いときに `true` になる。

使うPoseランドマークは左肘13・左手首15・右肘14・右手首16である。

左右それぞれで、肘から手首へ向かう前腕の角度を計算する。

- 水平: 角度が0°付近または180°付近から±30°以内
- 鉛直: 角度が90°または-90°付近から±30°以内

さらに、左右の「肘から手首」の線分間の最短距離を計算する。線分が交差する場合は距離を0とする。

最終判定は、次の条件をすべて満たすときに `true` となる。

- 前腕どうしの最短距離が0.1以下
- 左右のどちらか一方が水平、もう一方が鉛直

## 実装すること

- `CrossArmsExplanation` に、左右の肘・手首を結ぶ前腕の線を表示する。
- 前腕の角度、水平・鉛直の判定、線分間距離を表示する。
- `actionDetails.closs` に、左右の角度・向きの真偽・線分間距離・しきい値を追加する。

## 受け入れ条件

- [ ] 左右の前腕と、使う肘・手首の骨格点を確認できる。
- [ ] 水平・鉛直の許容範囲を確認できる。
- [ ] 線分間距離としきい値0.1を表示できる。
- [ ] 実機で `actions.closs` の判定と説明表示が一致する。
