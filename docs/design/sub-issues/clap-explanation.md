# たたく動作の判定過程を可視化する

## 親issue

[動作解説コンポーネントの実装ガイド](../explanation-panel-common-issue.md)

## 現在の判定

`actions.clap` は、2本の手のランドマーク12どうしが近づいたときに `true` になる。

使うHandsランドマークは、検出した1本目の手の12番と、2本目の手の12番である。

```text
distance = sqrt((hand1[12].x - hand2[12].x)^2 + (hand1[12].y - hand2[12].y)^2)
```

次の条件を満たすと最終判定が `true` になる。

- 2点の距離が `0.05` 未満

手を2本検出できない場合は、判定しない。

## 実装すること

- `ClapExplanation` に、2本の手の12番ランドマークと、その間を結ぶ線を表示する。
- 2点間距離としきい値0.05を表示する。
- `actionDetails.clap` に、2点の座標・距離・しきい値・手の検出数を追加する。

## 受け入れ条件

- [ ] 判定に使う2つの手の12番ランドマークを確認できる。
- [ ] 2点間距離としきい値0.05を表示できる。
- [ ] 手を2本検出できない場合の表示がある。
- [ ] 実機で `actions.clap` の判定と説明表示が一致する。
