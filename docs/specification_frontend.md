# フロントエンド仕様書

本プロジェクトのフロントエンドは、Webブラウザ上でカメラからリアルタイムに人物の骨格（ポーズ）を検出し、そのデータをバックエンドへ中継送信する機能、およびバックエンドからデータを受け取って骨格を可視化する視聴機能を持ちます。また、教育向けのアニメーション再生機能を備えています。

---

## 1. 使用言語・フレームワーク・主要ライブラリ

- **言語**: TypeScript
- **フレームワーク**: React (v19.2.6)
- **ビルドツール**: Vite (v8.0.12)
- **主要ライブラリ**:
  - **`@mediapipe/tasks-vision`**: MediaPipeのWeb用パッケージ。機械学習によるリアルタイム骨格検出（Pose Landmarker）に使用。
  - **`manim-web`**: Pythonの人気数学アニメーションライブラリ「Manim」のWeb（JavaScript/Canvas）移植版。動的なプログラミング概念解説アニメーションの描画に使用。

## 3. 機能別の説明

### ① 簡易パスワード認証ガード (`AuthGuard`)
- **機能詳細**: 
  特定のパスワードを入力するまでアプリケーションの主要機能へのアクセスを制限するセキュリティコンポーネントです。一度認証が完了すると、セッション中は認証状態が保持されます。
- **アルゴリズム**:
  1. `sessionStorage` に保存された認証状態（キー: `opencampus_auth_authenticated`）を初期値としてロード。
  2. 未認証の場合、パスワード入力フォームを表示。
  3. パスワード送信時、バックエンドの `/api/webrtc/auth/verify/` に対し POST リクエストで検証を要求。
  4. レスポンスが `200 OK` であれば、`sessionStorage` に認証成功フラグを書き込み、子コンポーネント（メイン画面）を描画する。

### ② リアルタイム骨格検出・送信機能 (`VideoPanel` - 送信モード)
- **機能詳細**: 
  ユーザーのWebカメラから映像ストリームを取得し、MediaPipeを用いてリアルタイムに身体の関節点（ランドマーク）を検出します。検出された骨格座標とキャプチャ画像をバックエンドサーバーへ定期的に送信します。
- **アルゴリズム**:
  1. `navigator.mediaDevices.getUserMedia({ video: true })` によりカメラの映像ストリームを取得し、`<video>` 要素にバインドして再生。
  2. WebAssemblyベースの MediaPipe `PoseLandmarker` インスタンスを初期化し、読み込み。
  3. 120ms 間隔でタイマー（`setTimeout` による再帰呼び出し）を回し、ビデオフレームから骨格点を検出（`detectForVideo`）。
  4. 検出された 33 点の 3 次元座標を `[0.0, 1.0]` にクランプ・正規化した `PoseFrame` オブジェクトを作成。
  5. ポーズ送信間隔（最低 120ms）を満たしている場合、`/api/webrtc/pose/update/` へ JSON POST 送信。
  6. 同時に、非表示の `<canvas>` を用いて現在のカメラフレームを `image/jpeg` 形式（品質 0.5）の Base64 文字列に変換し、`/api/webrtc/image/update/` へ POST 送信。

### ③ 骨格データの視聴・可視化機能 (`VideoPanel` - 視聴モード)
- **機能詳細**: 
  バックエンドから配信される特定のルーム（`room_id`）の最新の骨格座標データおよび画像データを受信し、`<canvas>` 上にリアルタイムに描画します。
- **アルゴリズム**:
  1. 150ms 間隔でバックエンドの `/api/webrtc/pose/latest/?room_id=...` および `/api/webrtc/image/latest/?room_id=...` に対してポーリング（GETリクエスト）を実行。
  2. **表示モード制御**:
    - 「映像のみ」「骨格のみ」「同時表示（映像の上に骨格を重ねる）」の 3 モードをサポート。
    - 受信した画像データを `HTMLImageElement` として読み込み、Canvas 上に描画（背景画像）。
  3. **骨格描画（`drawPoseFrame`）**:
    - 取得したランドマークの座標から、あらかじめ定義された関節の接続リスト（`POSE_CONNECTIONS` 例: 肩と肘、肘と手首など）に従って 2D 線を描画。
    - 各関節（関節点）を円としてプロット。
  4. **部位ハイライト**:
    - ユーザーが選択したハイライト部位（顔・頭部、左腕、右腕、下半身）に対応する関節インデックス（例: 左腕なら `[11, 13, 15]`）を抽出。
    - 描画時、該当する関節点の円をネオンイエロー等の強調色で描画し、視認性を高める。

### ④ 動的アニメーション再生機能 (`AnimationPanel`)
- **機能詳細**: 
  `manim-web` ライブラリを使用して作成されたプログラミング学習用のアニメーションシーン（Mobject やアニメーション効果）を再生します。
- **アルゴリズム**:
  1. React の `ResizeObserver` APIにより、描画エリアのサイズ（幅・高さ）を動的に計測し、`<ManimScene>` コンポーネントに反映。
  2. シーンオブジェクト（`Scene`）が構築され準備が完了したタイミング（`onSceneReady`）で、非同期ループ処理を開始。
  3. 各シーン定義（例: `forGhost` シーン）に実装されている非同期関数 `construct(scene)` を実行してアニメーションを描画。
  4. アニメーションが最後まで到達したら `scene.clear()` を行い、再度 `construct(scene)` を呼び出すことで無限ループ再生を実現。

### ⑤ プログラミング学習用シーン (`forGhost` / `example`)
- **機能詳細**: 
  プログラムの「for文（繰り返し処理）」を直感的に理解できるよう、「おばけ退治」に例えたアニメーションを描画します。
- **アルゴリズム**:
  1. `Circle`, `Rectangle`, `Text` などの 2D/3D ベクターオブジェクト（Mobject）を生成し、画面上に配置（初期状態）。
  2. `scene.play()` メソッドに `FadeIn`（出現）や `Write`（文字書き込み）のアニメーションを渡して実行。
  3. プログラミングの `for` ループ構成を模し、「手を叩く（3回）」「ジャンプ（2回）」「しゃがむ（3回）」の各動作ステップを順番に処理。
  4. プレイヤーオブジェクトのパーツ（腕や足など）を `animate.moveTo()` を用いて動かすことで、キャラクターの動作アニメーションを表現。
  5. 規定回数に到達すると、おばけオブジェクト（👻）のスケールを縮小（`scale(0.2)`）して退治される演出を行い、スコア獲得テキストをアニメーション表示。
